# RawNet2 Model for PhaseGuard

## Model Download

RawNet2 is a lightweight CNN-RNN model for audio deepfake detection.

### Official Source
- **Repository:** https://github.com/StarStop/ASV-GAN-DF
- **Model:** RawNet2
- **License:** MIT

### Download Instructions

1. Clone the repository:
```bash
cd models/rawnet2
git clone https://github.com/StarStop/ASV-GAN-DF.git
```

2. Convert to ONNX format if needed (PyTorch to ONNX)

3. Place the ONNX model in: `models/rawnet2/rawnet2.onnx`
